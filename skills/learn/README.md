# learn

Learning the Microsoft stack yourself, and teaching it to others.

Microsoft Learn is free, enormous and genuinely good, so this bucket stays deliberately small. A skill earns a place here only if it does something documentation structurally cannot: work out what a particular person has misunderstood, sequence across products that Learn documents separately, teach against a real project rather than a sample, or say plainly that something is not worth learning.

## Model-invoked

Reachable by you, or reached for automatically when the task fits.

- [explain-concept](./explain-concept/SKILL.md) - explain a Microsoft ecosystem concept after diagnosing what the person actually misunderstands, rather than answering the question they typed.
