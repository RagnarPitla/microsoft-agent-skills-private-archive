# Code of conduct

## The standard

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. Read it there rather than here - it is maintained upstream, and a
copy in this repository would go stale the way every copied document does.

## What that means in practice here

Most of what happens in this repository is disagreement about whether a technical
claim is true. That is the point, and it is welcome. Two things keep it useful:

**Argue with the claim, not the person.** "This is wrong because the connector
does not support that auth mode unattended" is the whole job. "Anyone who thinks
that has not shipped anything" is not, even when the first half is correct.

**Be willing to be wrong in public.** Skills here get corrected. A maintainer
being shown a retired CLI flag is the system working, not an attack, and it will
be treated that way.

## Reporting

Report unacceptable behaviour privately to the repository owner,
[@RagnarPitla](https://github.com/RagnarPitla), through GitHub. Reports are
handled confidentially. Because this repository is maintained by one person, a
report about that person is better sent to GitHub Support, which can act
independently.

## Scope

This applies in issues, pull requests, discussions and commit messages here, and
to anyone representing the project elsewhere.
